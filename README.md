# Wedding Invitation Template

A multilingual static wedding invitation for GitHub Pages.

Languages:
- `/` — Bahasa Indonesia
- `/ja/` — 日本語
- `/en/` — English

## Setup

1. Create a GitHub repository, for example `wedding-invitation`.
2. Copy all files in this folder into the repository.
3. Replace `[Name]`, dates, venue details, text, and placeholder images.
4. Edit `js/script.js` to set the exact wedding date/time.
5. Enable GitHub Pages under Settings → Pages → Deploy from branch.

## Photos

Replace:
- `assets/hero-placeholder.svg`
- `assets/story-placeholder.svg`
- `assets/photo-placeholder.svg`

You can instead use JPG/WEBP files and change the image paths in the HTML/CSS.

## RSVP

Replace the RSVP `href="#"` with your Google Form, Typeform, or another RSVP URL.
